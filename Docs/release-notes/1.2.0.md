## What's new in 1.2.0

- **Live download progress** — installing packages now shows a live progress bar, with a Downloads popover and per-package progress in the Library.
- **Faster launch** — shimmering placeholders appear while the catalog and inventory load, instead of an empty window.
- **In-app updates** — Brewery now checks for updates on launch (toggleable in Diagnostics) and shows a floating card when a new version is available.
- **Sudo authentication** — the Diagnostics page now explains how this Mac's sudo will authenticate (Touch ID, smartcard, or password).
