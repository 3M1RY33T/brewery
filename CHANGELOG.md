# Brewery changelog

Release notes shown in the in-app update card's "What's new" and on the GitHub release.

## 1.2.0

- Live download progress for installing packages, with a Downloads popover and per-package progress bars in the Library.
- Shimmering skeleton placeholders while the catalog and inventory load at launch.
- In-app updates via Sparkle: check on launch (toggleable in Diagnostics) with a floating update card.
- Touch ID detection surfaced on the Diagnostics page.
